# CIA Triad Analysis

## Project Overview

The CIA Triad is a fundamental concept in information security. It consists of three core principles: Confidentiality, Integrity, and Availability.

This project analyzes five real-world cybersecurity incidents to understand how security failures affect these three principles.

## Objectives

- Understand the three core principles of information security.
- Analyze five real-world cybersecurity incidents.
- Classify incidents according to CIA principles.
- Understand the importance of information security.

## CIA Triad Principles

### 1. Confidentiality

Confidentiality ensures that sensitive information is accessible only to authorized individuals.

### 2. Integrity

Integrity ensures that information remains accurate, complete, and protected from unauthorized modifications.

### 3. Availability

Availability ensures that information and services remain accessible to authorized users whenever required.

## Real-World Examples

The following five cybersecurity incidents will be analyzed:

1. Yahoo Data Breach
2. Equifax Data Breach
3. SolarWinds Cyberattack
4. WannaCry Ransomware Attack
5. Dyn DDoS Attack

## Project Approach

Each incident is analyzed based on its impact on confidentiality, integrity, and availability. The primary affected security principle is identified for each incident.

## Expected Outcome

This project demonstrates how real-world cybersecurity incidents can affect confidentiality, integrity, and availability.

## Conclusion

The CIA Triad provides a foundation for information security. Understanding confidentiality, integrity, and availability helps organizations protect sensitive information and maintain secure systems.
